# Discrete Math

*This course is a work in progress.*

This course covers basic discrete mathematics, which are foundational to theoretial computer science.

This course uses Oscar Levin's [Discrete Mathematics: An Open Introdution](https://discrete.openmathbooks.org/dmoi4/dmoi4.html). Recommended homework problems are taken from this textbook.
