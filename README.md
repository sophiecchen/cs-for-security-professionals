# Computer Science for Security Professionals

This is a series of computer science mini courses covering content you would likely learn as a computer science major at university.

These presentations are not a replacement for university courses; rather, they were made for cybersecurity professionals who do not have a computer science background.

| Course | Prerequisites | Lectures | 
| - | - | - |
| [Discrete Math](./discrete-math/) | None | 0/9 completed |
| [Data Structures and Algorithms](./data-structures-algorithms/) | Discrete Math, basic programming | 0/16 completed |
| [Theoretical Foundations](./theoretical-foundations/) | Discrete Math | 0/10 completed |
| [Computer Systems](./computer-systems/) | Data Structures and Algorithms | 0/15 completed |
| [Cryptography](./cryptography/) | Theoretical Foundations | 0/8 completed |

## Acknowledgements

Content choices are influenced by what I learned at the University of Michigan and Carnegie Mellon University. However, all slides have been made from scratch using publically available information.
