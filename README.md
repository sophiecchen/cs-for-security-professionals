# Computer Science for Security Professionals

This is a series of computer science "courses" (i.e. powerpoint slides with speaker notes and recommendations) covering content you would likely learn as a computer science major at university.

These presentations are not a replacement for university courses; rather, they were made for cybersecurity professionals who do not have a computer science background.

| Course | Prerequisites | Lectures | 
| - | - | - |
| [Discrete Math](./discrete-math/) | None | 0/? completed |
| [Data Structures and Algorithms](./data-structures-algorithms/) | Discrete Math, basic programming | 0/? completed |
| [Theoretical Foundations](./theoretical-foundations/) | Discrete Math | 0/? completed |
| [Computer Systems](./computer-systems/) | Data Structures and Algorithms | 0/? completed |
| [Cryptography](./cryptography/) | Theoretical Foundations | 0/? completed |
