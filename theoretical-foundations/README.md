# Theoretical Foundations

*This course is a work in progress.*

This course covers theoretical foundations for computer science, focusing on computability and complexity. A background in discrete math (such as through the Discrete Math course) is required.

This course follows Amir Kamil's [Foundations of Computer Science](https://eecs376.github.io/notes/), written for University of Mihigan's EECS 376 course.
